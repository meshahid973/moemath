# Native M PLUS 1p assets

Regular (400), Bold (700), ExtraBold (800), from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/mplus1p), licensed under the accompanying SIL OFL 1.1.

TTFs subset with fontTools 4.63.0: U+0000–024F, U+2000–22FF and U+6570. This retains English/extended Latin, punctuation, arrows, available math glyphs and the 数 glyph. The six Suu-chan illustrations are unchanged. No font is downloaded at runtime.

The three fonts total 282,952 bytes. Verified glyphs include `0123456789+−×÷%=.,±数`. Other scripts use native font fallback. Keep license/copyright metadata when changing these assets.
